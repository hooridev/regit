## Configuring Remotes

`Remote` handles read and write standard `[remote "<name>"]` sections in `.git/config`, supporting both local filesystem paths and HTTP(S) URLs.

```java title="ConfigureRemotes.java"
// Register a Smart HTTP endpoint or a local bare repository
Remote origin = repo.addRemote("origin", "https://git.example.org/team/app.git");
Remote backup = repo.addRemote("backup", Path.of("/srv/git/app.git"));

// List configured remotes or look up by name
List<Remote> remotes = repo.remotes();
Remote loaded = repo.remote("origin");

// Remove a remote from .git/config
repo.removeRemote(backup);
```

## Fetch & Prune (`git fetch --prune`)

`fetch(...)` updates all remote-tracking refs under `refs/remotes/<remote>/*` without modifying your checked-out branch or working tree:

```java title="FetchAndPrune.java"
Remote origin = repo.remote("origin");

// Fetch all remote branches and prune deleted ones (`git fetch origin --prune`)
FetchResult fetched = repo.fetch(origin, FetchOptions.defaults().prune());

fetched.updated().forEach((rb, oid) ->
    System.out.println("updated " + rb.fullName() + " -> " + oid.substring(0, 7)));
fetched.pruned().forEach(rb ->
    System.out.println("pruned  " + rb.fullName()));

// Use the fetched RemoteBranch directly as a CommitRef
RemoteBranch originMain = repo.remoteBranch("origin", "main");
Diff behind = repo.diff(repo.currentBranch(), originMain);
```

## Push Modes (`-u`, `-f`, `--force-with-lease`, `--delete`)

```java title="PushModes.java"
Remote origin = repo.remote("origin");
Branch current = repo.currentBranch();

// 1. Standard fast-forward push
repo.push(origin);

// 2. Push and configure upstream tracking (`git push -u origin <branch>`)
repo.push(origin, PushOptions.defaults().setUpstream());

// 3. Safe force push verified against local remote-tracking ref (`git push --force-with-lease`)
repo.push(origin, PushOptions.defaults().forceWithLease());

// 4. Force push verified against an explicit expected CommitRef
Commit expected = repo.commit("origin/main");
repo.push(origin, current, "main", PushOptions.defaults().forceWithLease(expected));

// 5. Unconditional force push (`git push -f`)
repo.push(origin, PushOptions.defaults().force());

// 6. Delete a remote branch (`git push origin --delete feat/old`)
repo.deleteRemoteBranch(origin, "feat/old");
// Or pass a RemoteBranch object directly:
repo.deleteRemoteBranch(repo.remoteBranch("origin", "feat/old"));
```

## Smart HTTP with Custom `HttpClient` (Auth & TLS)

Your application keeps full control over authentication, proxies, timeouts, and TLS configuration via the standard `java.net.http.HttpClient`:

```java title="SmartHttpAuth.java"
import java.net.*;
import java.net.http.HttpClient;
import java.time.Duration;

HttpClient client = HttpClient.newBuilder()
    .connectTimeout(Duration.ofSeconds(10))
    .authenticator(new Authenticator() {
        @Override
        protected PasswordAuthentication getPasswordAuthentication() {
            return new PasswordAuthentication("git-bot", System.getenv("GIT_TOKEN").toCharArray());
        }
    })
    .build();

Remote origin = repo.remote("origin");
repo.fetch(origin, FetchOptions.defaults().prune().httpClient(client));
repo.push(origin, PushOptions.defaults().setUpstream().httpClient(client));
```

## Hosting a Bare Repository over Smart HTTP

Mount any bare repository directly on the JDK's built-in `HttpServer` using `httpHandler(...)` — interoperable with native `git clone`, `git fetch`, and `git push`:

```java title="HostBareRepo.java"
import com.sun.net.httpserver.HttpServer;
import io.github.regit.*;
import java.net.InetSocketAddress;
import java.nio.file.Path;

Repository central = Repository.initBare(Path.of("/srv/repos/team.git"), "main");

HttpServer server = HttpServer.create(new InetSocketAddress("127.0.0.1", 8080), 0);
server.createContext("/team.git", central.httpHandler(GitHttpHandler.Access.READ_WRITE));
server.createContext("/mirror.git", central.httpHandler(GitHttpHandler.Access.READ_ONLY));
server.start();
```

<Callout type="warn" title="Authentication & TLS">
  `GitHttpHandler` implements Git Smart HTTP v0 with pack validation, ref locking, and built-in size limits (256 MiB body / 100,000 pack records). Supply authentication and TLS via a JDK HTTP filter or a reverse proxy when exposing repositories beyond localhost.
</Callout>
