`regit`'s diff engine uses the **Myers algorithm** (`O((N+M)D)`) to produce Git-compatible unified hunks complete with section headers, binary detection, and `\ No newline at end of file` markers.

## The 4 Most Common Diff Comparisons

```java title="CommonDiffs.java"
// 1. Unstaged changes: Working Tree vs. Index (`git diff`)
Diff unstaged = repo.diff();

// 2. Staged changes: Index vs. HEAD (`git diff --cached`)
Diff staged = repo.diffStaged();

// 3. Working Tree against any CommitRef (`git diff <rev>`)
Diff vsHead = repo.diffWorktree(repo.currentBranch());
Diff vsBase = repo.diffWorktree(repo.remoteBranch("origin", "main"));

// 4. Compare any two commits or branches (`git diff <from> <to>`)
Branch main = repo.branch("main");
Branch feature = repo.branch("feature/search");
Diff branchDiff = repo.diff(main, feature);
```

## Output Formats & Quick Checks

Every `Diff` object exposes both structured Java models and Git-compatible text formatters:

```java title="DiffFormats.java"
Diff diff = repo.diffStaged();

// Fast emptiness check (`git diff --quiet`)
if (diff.isEmpty()) {
    System.out.println("No changes.");
    return;
}

// Changed file paths only (`git diff --name-only`)
List<String> changedFiles = diff.names();

// Compact summary line (`git diff --shortstat`)
// e.g. " 2 files changed, 14 insertions(+), 3 deletions(-)"
String shortStat = diff.formatShortStat();

// Structured counts
DiffStat stat = diff.stat();
System.out.printf("%d files, +%d / -%d%n",
    stat.filesChanged(), stat.insertions(), stat.deletions());

// Diffstat table (`git diff --stat`)
System.out.println(diff.formatStat());

// Full unified patch (`git diff`)
System.out.println(diff.formatPatch());

// Inline word-level diff (`git diff --word-diff`, markers: [-old-]{+new+})
System.out.println(diff.formatWordDiff());
```

## Options: `-U<n>`, `--diff-filter`, `-M` & Path Filters

Configure context lines, change filters, rename detection, and path scopes using the immutable `DiffOptions` builder:

```java title="DiffOptionsExample.java"
DiffOptions options = DiffOptions.defaults()
    .contextLines(1)                                           // -U1
    .detectRenames()                                           // -M (default 50% similarity)
    .filter(FileDiff.Change.MODIFIED, FileDiff.Change.RENAMED) // --diff-filter=MR
    .paths(Path.of("src/main"));                               // -- src/main

Diff filtered = repo.diff(repo.getCommit("HEAD~5"), repo.headCommit().orElseThrow(), options);

for (FileDiff file : filtered.files()) {
    if (file.change() == FileDiff.Change.RENAMED) {
        System.out.printf("Renamed %s -> %s (%d%%)%n",
            file.oldPath(), file.newPath(), file.similarity());
    }
    for (DiffHunk hunk : file.hunks()) {
        System.out.println(hunk.header());
        for (DiffLine line : hunk.lines()) {
            System.out.print(line.prefix() + line.content());
        }
    }
}
```

## Showing a Commit Diff (`git show`)

`showDiff(...)` diffs a commit against its first parent (or against the empty tree for a root commit):

```java title="ShowCommitDiff.java"
Commit head = repo.headCommit().orElseThrow();
CommitDiff shown = repo.showDiff(head, DiffOptions.defaults().detectRenames());

System.out.println(shown.commit().shortId() + " " + shown.commit().subject());
System.out.println(shown.diff().formatStat());
System.out.println(shown.diff().formatPatch());
```
