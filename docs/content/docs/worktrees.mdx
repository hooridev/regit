---
title: Worktrees (Multi-Agent Workflow)
description: Isolated checkouts per task or agent with independent indexes, HEADs, and concurrent commits.
---

Linked worktrees share the repository's object database (`.git/objects`) and refs, while maintaining their own **HEAD**, **index**, and **operation lock**. Multiple threads or AI agents can modify files and commit concurrently on separate branches without interfering with one another.

## Adding Worktrees (`git worktree add`)

<Tabs items={['New Branch (-b)', 'Existing Branch', 'Detached HEAD (--detach)', 'Force (--force)']}>
  <Tab value="New Branch (-b)">
```java title="WorktreeNewBranch.java"
// Create a new branch from HEAD or any CommitRef and check it out in a new directory
Repository agent = mainRepo.addWorktreeNewBranch(
    Path.of("/tmp/wt-docs"),
    "agent/docs",
    mainRepo.remoteBranch("origin", "main")
);
```
  </Tab>
  <Tab value="Existing Branch">
```java title="WorktreeExistingBranch.java"
Branch topic = mainRepo.createBranch("agent/refactor");
Repository agent = mainRepo.addWorktree(Path.of("/tmp/wt-refactor"), topic);
```
  </Tab>
  <Tab value="Detached HEAD (--detach)">
```java title="WorktreeDetached.java"
// Ideal for read-only analysis, builds, or test runs pinned to a specific commit or tag
Commit release = mainRepo.commit("v1.0");
Repository buildWt = mainRepo.addWorktreeDetached(Path.of("/tmp/wt-build"), release);
```
  </Tab>
  <Tab value="Force (--force)">
```java title="WorktreeForce.java"
// Allow checking out a branch that is already checked out in another worktree
Repository copy = mainRepo.addWorktree(
    Path.of("/tmp/wt-main-copy"),
    mainRepo.branch("main"),
    WorktreeAddOptions.defaults().force()
);
```
  </Tab>
</Tabs>

## Listing Worktrees (`git worktree list --porcelain`)

```java title="ListWorktrees.java"
for (WorktreeInfo wt : mainRepo.worktreeList()) {
    String refLabel = wt.bare()
        ? "(bare)"
        : wt.detached()
            ? "(detached)"
            : wt.branch().map(Branch::name).orElse("(unborn)");

    System.out.printf("%-35s %s %-20s%s%n",
        wt.path(),
        wt.head().map(id -> id.substring(0, 7)).orElse("-------"),
        refLabel,
        wt.locked() ? " [locked]" : "");
}
```

## Removing Worktrees (`git worktree remove`)

```java title="RemoveWorktree.java"
// Safe removal: fails if staged, unstaged, or untracked files are present
mainRepo.removeWorktree(agent);

// Or by path
mainRepo.removeWorktree(Path.of("/tmp/wt-docs"));

// Forced removal (`git worktree remove --force`): removes dirty checkouts as well
mainRepo.removeWorktreeForce(agent);
```

## Concurrent Multi-Agent Commits with Virtual Threads

Because each worktree owns its own index and operation lock, agents can commit in parallel and merge cleanly back into `main`:

```java title="ParallelAgents.java"
import io.github.regit.*;
import java.nio.file.*;
import java.time.OffsetDateTime;
import java.util.concurrent.Executors;

var author = new Identity("Agent", "agent@example.org", OffsetDateTime.now());
Repository mainRepo = Repository.open(Path.of("project"));

Path dirA = Path.of("wt-agent-a");
Path dirB = Path.of("wt-agent-b");
Repository agentA = mainRepo.addWorktreeNewBranch(dirA, "agent/api");
Repository agentB = mainRepo.addWorktreeNewBranch(dirB, "agent/docs");

try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    var taskA = executor.submit(() -> {
        Files.writeString(dirA.resolve("Api.java"), "public interface Api {}\n");
        agentA.stageAll();
        return agentA.commit("feat: add Api\n", author, author, CommitOptions.defaults());
    });
    var taskB = executor.submit(() -> {
        Files.writeString(dirB.resolve("GUIDE.md"), "# Guide\n");
        agentB.stageAll();
        return agentB.commit("docs: add Guide\n", author, author, CommitOptions.defaults());
    });

    taskA.get();
    taskB.get();
}

// Merge directly by passing the agent's Repository handle
mainRepo.merge(agentA, author, "merge: agent/api\n");
mainRepo.merge(agentB, author, "merge: agent/docs\n");

// Clean up worktrees and branches
mainRepo.removeWorktree(agentA);
mainRepo.removeWorktree(agentB);
mainRepo.deleteBranch("agent/api");
mainRepo.deleteBranch("agent/docs");
```
