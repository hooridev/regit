**regit** implements Git operations directly in **Java 25** — with zero runtime dependencies, no JGit, and no `git` subprocesses. All written objects, indexes, refs, worktrees, and conflict states are 100% interoperable with native Git.

<Callout type="info" title="Object-oriented API instead of string flags">
  Rather than assembling CLI strings, `regit` works with first-class domain objects such as `Repository`, `Branch`, `RemoteBranch`, `Commit`, `CommitRef`, `Diff`, `Log`, `MergeOptions`, and `RebaseOptions`.
</Callout>

## 30-Second Quickstart

The snippet below initializes a repository, creates an initial commit, isolates work on a feature branch inside a linked worktree, inspects the diff, merges back into `main`, and cleans up:

```java title="Quickstart.java"
import io.github.regit.*;
import java.nio.file.*;
import java.time.OffsetDateTime;

Path repoDir = Path.of("my-project");
var author = new Identity("Alix", "alix@example.org", OffsetDateTime.now());

// 1. Initialize repository and create the first commit
Repository mainRepo = Repository.init(repoDir, "main");
Files.writeString(repoDir.resolve("README.md"), "# My Project\n");
mainRepo.stageAll();
Commit initial = mainRepo.commit("feat: initial commit\n", author);

// 2. Create an isolated worktree for a task or agent
Path featureDir = Path.of("my-project-docs");
Repository agent = mainRepo.addWorktreeNewBranch(featureDir, "agent/docs", initial);

Files.writeString(featureDir.resolve("README.md"), "# My Project\n\nWith documentation.\n");
agent.stageAll();
Commit docsCommit = agent.commit("docs: update README\n", author);

// 3. Inspect the diff between commits
Diff diff = mainRepo.diff(initial, docsCommit);
System.out.println(diff.formatStat());
System.out.println(diff.formatPatch());

// 4. Merge back into main and clean up worktree & branch
Branch docsBranch = mainRepo.branch("agent/docs");
mainRepo.merge(docsBranch, author, "merge: integrate docs\n", MergeOptions.defaults().noFastForward());
mainRepo.removeWorktree(agent);
mainRepo.deleteBranch(docsBranch);
```

## The `CommitRef` Model

Many Git operations accept any target that resolves to a commit. In `regit`, those types share the sealed interface `CommitRef`:

- `Commit` — immutable commit snapshot (returned by `headCommit()`, `commit(...)`, `log(...)`, etc.)
- `Branch` — repository-scoped local branch handle that always resolves to its live tip
- `RemoteBranch` — remote-tracking branch handle (e.g. `origin/main`)
- `CommitRef.of("HEAD~2")` — arbitrary Git revision expressions (`v1.0`, `HEAD^2`, short SHAs)

```java title="CommitRefExample.java"
Branch main = repo.branch("main");
RemoteBranch originMain = repo.remoteBranch("origin", "main");
Commit release = repo.commit("v1.0");

// Mix and match objects directly without string conversions
boolean merged = repo.isAncestor(release, main);
Optional<Commit> base = repo.mergeBase(originMain, main);
Diff changes = repo.diff(originMain, main);
String readme = repo.showText(release, Path.of("README.md"));
```
