## Creating & Opening Repositories

```java title="OpenOrInit.java"
import dev.hoori.regit.Repository;
import java.nio.file.Path;

// Create a new working-tree repository (default branch "main", or specify explicitly)
Repository repo = Repository.init(Path.of("/tmp/demo"));
Repository custom = Repository.init(Path.of("/tmp/demo-dev"), "develop");

// Create a bare repository (default branch "main")
Repository bare = Repository.initBare(Path.of("/tmp/central.git"));

// Open an existing working tree, linked worktree, or bare repository
Repository opened = Repository.open(Path.of("/tmp/demo"))
    .withAuthor("Alix", "alix@example.org"); // optional default identity for commits/merges/rebases
boolean isBare = opened.isBare();
```

### Reading Git Config & Identity

Read effective configuration values across global (`$XDG_CONFIG_HOME/git/config`, `~/.gitconfig`), repository, and worktree config (`config.worktree` when `extensions.worktreeConfig` is enabled), or resolve the configured `user.name` and `user.email` into an `Identity`:

```java title="ConfigIdentity.java"
// Resolve user.name and user.email (empty if either is unset or blank)
Optional<Identity> configured = repo.configuredIdentity();
// withAuthor(name, email) stamps each commit with its own time; withAuthor(Identity) would reuse one timestamp
Repository authored = configured.map(id -> repo.withAuthor(id.name(), id.email())).orElse(repo);

// Read any config key (section.key or section.subsection.key)
Optional<String> remoteUrl = repo.config("remote.origin.url");
```

## Paths & HEAD State (`git rev-parse`)

All common `rev-parse` metadata queries are directly available as strongly typed methods on `Repository`:

```java title="RevParsePaths.java"
// --show-toplevel (empty for bare repositories)
Optional<Path> topLevel = repo.worktreeRoot();

// --git-dir (worktree-specific administrative directory)
Path gitDir = repo.gitDir();

// --git-common-dir (shared .git directory across all linked worktrees)
Path commonDir = repo.commonDir();

// --abbrev-ref HEAD ("main", or "HEAD" when detached)
String abbrev = repo.abbrevRef();
boolean detached = repo.isDetachedHead();

// Current local branch as Optional (empty on detached HEAD, like `git branch --show-current`)
Optional<Branch> currentBranch = repo.currentBranchOptional();

// Current HEAD commit (works attached, detached, and on unborn branches)
Optional<String> headOid = repo.head();
Optional<Commit> headCommit = repo.headCommit();
```

### Resolving Revisions & Unique Short IDs

`resolve(...)` supports Git revision syntax including lightweight and annotated tags, `~`/`^` operators, peel syntax (`^{tree}`, `^{commit}`), `<rev>:<path>`, and `:<path>` (index stage 0).

```java title="ResolveRevisions.java"
// Resolve to full 40-character SHA-1
String headSha   = repo.resolve("HEAD");
String treeSha   = repo.resolve("HEAD^{tree}");
String parentSha = repo.resolve("HEAD~2");
String blobSha   = repo.resolve("HEAD:src/main/App.java");
String stagedSha = repo.resolve(":src/main/App.java");

// Collision-free abbreviated object ID (`git rev-parse --short` / `--short=10`)
String short7  = repo.shortId("HEAD");
String short10 = repo.shortId(repo.currentBranch(), 10);

// Load a Commit object directly
Commit head      = repo.getCommit("HEAD");
Commit tagCommit = repo.getCommit("v1.2.0");
Commit branchTip = repo.getCommit(repo.branch("main"));

System.out.printf("%s %s (%s)%n", head.shortId(), head.subject(), head.author().name());
```

## Reading Files & Trees from Revisions (`git show rev:path`)

Use `showText(...)`, `showBlob(...)`, and `listTree(...)` to inspect historical file versions and directory trees directly from the object database — even in bare repositories and without touching the working tree.

<Tabs items={['Object-Oriented (Commit / Branch)', 'Git Syntax (rev:path)']}>
  <Tab value="Object-Oriented (Commit / Branch)">
```java title="ShowWithObjects.java"
Branch main = repo.branch("main");
Commit previous = repo.getCommit("HEAD~1");

// Read UTF-8 text from a Branch or Commit
String currentPom = repo.showText(main, "pom.xml");
String oldReadme  = repo.showText(previous, Path.of("README.md"));

// Read raw binary bytes
byte[] iconBytes = repo.showBlob(main, "assets/icon.svg");
```
  </Tab>
  <Tab value="Git Syntax (rev:path)">
```java title="ShowWithRevPath.java"
// Any rev:path expression
String fromTag    = repo.showText("v1.0:README.md");
String fromParent = repo.showText("HEAD~2:src/Main.java");

// Read staged index contents (:path)
String stagedContent = repo.showText(":README.md");
byte[] stagedBytes   = repo.showBlob(":assets/logo.png");
```
  </Tab>
</Tabs>

### Listing Directory Trees (`git ls-tree`)

```java title="ListTree.java"
Commit head = repo.headCommit().orElseThrow();

// Root tree of a commit
List<TreeEntry> rootEntries = repo.listTree(head);

// Specific subdirectory (accepts String or Path)
List<TreeEntry> srcEntries = repo.listTree(head, Path.of("src/main/java"));

for (TreeEntry entry : srcEntries) {
    System.out.printf("%-7s %s %s%s%n",
        entry.type(),
        entry.id().substring(0, 7),
        entry.path(),
        entry.executable() ? " (+x)" : "");
}
```
