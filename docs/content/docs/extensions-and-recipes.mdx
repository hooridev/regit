## Lifecycle-Hooks (Policy-Veto & Audit-Log)

Mit `withLifecycle(...)` kannst du jede schreibende Operation vor der Ausführung prüfen (und per `IOException` blockieren) oder nach erfolgreicher Ausführung protokollieren. Verknüpfte Worktrees erben den Hook automatisch.

```java title="LifecyclePolicy.java"
import io.github.regit.*;
import java.io.IOException;

Repository guarded = repo.withLifecycle(new Lifecycle() {
    @Override
    public void before(Event event) throws IOException {
        // Beispiel: Direktes Pushen oder Löschen auf main verbieten
        if (event.operation() == Operation.DELETE_BRANCH && "main".equals(event.target())) {
            throw new IOException("Policy veto: main darf nicht gelöscht werden");
        }
    }

    @Override
    public void after(Event event) {
        System.out.printf("[AUDIT] %s auf %s (target=%s)%n",
            event.operation(), event.repository(), event.target());
    }
});
```

## Eigene `ContentMerge`-Strategie

Bei konkurrierenden Änderungen an derselben Datei kannst du für strukturierte Formate (z. B. `manifest.json`, Lockfiles, Changelogs) eine eigene Merge-Logik hinterlegen und alle anderen Dateien an `ContentMerge.text()` delegieren:

```java title="CustomContentMerge.java"
import io.github.regit.*;
import static java.nio.charset.StandardCharsets.UTF_8;

Repository smartRepo = repo.withContentMerge((path, base, current, incoming) -> {
    if (path.equals("VERSION")) {
        // Immer die höhere Versionszeile wählen
        String a = new String(current, UTF_8).strip();
        String b = new String(incoming, UTF_8).strip();
        return ((a.compareTo(b) >= 0 ? a : b) + "\n").getBytes(UTF_8);
    }
    return ContentMerge.text().merge(path, base, current, incoming);
});
```

## Kopierbare Praxis-Rezepte

### Rezept 1: Pull-Request-Vorbereitung (Fetch, Autosquash-Rebase, Safe Push)

Typischer Agenten-Workflow: aktuellen Stand von `origin/main` holen, `fixup!`-Commits sauber einfalten und sicher per `--force-with-lease` pushen.

```java title="PreparePullRequest.java"
Remote origin = repo.remote("origin");
var committer = new Identity("Dev Agent", "agent@example.org", OffsetDateTime.now());

// 1. Remote aktualisieren & veraltete Branches prunen
repo.fetch(origin, FetchOptions.defaults().prune());
RemoteBranch originMain = repo.remoteBranch("origin", "main");

// 2. Aktuellen Feature-Branch mit --autosquash auf origin/main rebasen
RebaseResult rebased = repo.rebase(
    originMain,
    committer,
    RebaseOptions.defaults().autosquash().allowConflicts()
);
if (rebased.isConflicted()) {
    throw new IllegalStateException("Rebase-Konflikt in: " + rebased.conflicts());
}

// 3. Diff-Zusammenfassung für die PR-Beschreibung erzeugen
Diff prDiff = repo.diff(originMain, repo.currentBranch(), DiffOptions.defaults().detectRenames());
System.out.println("PR-Umfang: " + prDiff.formatShortStat());

// 4. Sicher pushen (schlägt fehl, falls jemand anderes den Branch inzwischen geändert hat)
repo.push(origin, PushOptions.defaults().forceWithLease().setUpstream());
```

### Rezept 2: Alle bereits gemergten Feature-Branches aufräumen

```java title="CleanupMergedBranches.java"
Branch main = repo.branch("main");

for (Branch b : repo.mergedBranches(main)) {
    if (b.equals(main)) continue;
    System.out.println("Lösche gemergten Branch: " + b.name());
    repo.deleteBranch(b);
}
```

### Rezept 3: Gezielte Code-Analyse vor einem Release

```java title="ReleaseNotesGenerator.java"
Commit lastRelease = repo.commit("v1.0.0");
Branch main = repo.branch("main");

List<CommitDiff> changes = repo.logWithDiff(
    Log.range(lastRelease, main).noMerges(),
    DiffOptions.defaults().detectRenames()
);

System.out.println("## Änderungen seit " + lastRelease.shortId());
for (CommitDiff item : changes) {
    System.out.printf("- %s (%s) —%s%n",
        item.commit().subject(),
        item.commit().shortId(),
        item.stat().formatShortStat());
}
```

### Rezept 4: Sichere Änderungserkennung für CI / Automationen

```java title="CheckDirtyState.java"
Status st = repo.status();
boolean hasUncommitted = !st.staged().isEmpty()
    || !st.unstaged().isEmpty()
    || !st.untracked().isEmpty()
    || !repo.conflictedFiles().isEmpty();

if (hasUncommitted) {
    System.out.println("Arbeitsverzeichnis ist nicht sauber:");
    System.out.println(repo.diff().formatStat());
}
```
