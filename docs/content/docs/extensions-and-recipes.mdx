## Lifecycle Hooks (Policy Vetoes & Audit Logging)

Use `withLifecycle(...)` to inspect or veto any mutating operation before it takes effect (by throwing `IOException`), and to emit audit logs once an operation succeeds. Linked worktrees inherit configured hooks automatically.

```java title="LifecyclePolicy.java"
import dev.hoori.regit.*;
import java.io.IOException;

Repository guarded = repo.withLifecycle(new Lifecycle() {
    @Override
    public void before(Event event) throws IOException {
        // Example: prevent deleting main
        if (event.operation() == Operation.DELETE_BRANCH && "main".equals(event.target())) {
            throw new IOException("Policy veto: main cannot be deleted");
        }
    }

    @Override
    public void after(Event event) {
        System.out.printf("[AUDIT] %s on %s (target=%s)%n",
            event.operation(), event.repository(), event.target());
    }
});
```

## Custom `ContentMerge` Strategy

For structured files (such as manifests, lockfiles, or version files), provide a custom three-way merge policy and delegate all other paths to `ContentMerge.text()`:

```java title="CustomContentMerge.java"
import dev.hoori.regit.*;
import static java.nio.charset.StandardCharsets.UTF_8;

Repository smartRepo = repo.withContentMerge((path, base, current, incoming) -> {
    if (path.equals("VERSION")) {
        // Always pick the higher version line
        String a = new String(current, UTF_8).strip();
        String b = new String(incoming, UTF_8).strip();
        return ((a.compareTo(b) >= 0 ? a : b) + "\n").getBytes(UTF_8);
    }
    return ContentMerge.text().merge(path, base, current, incoming);
});
```

## Copy-Paste Recipes

### Recipe 1: Prepare a Pull Request (Fetch, Autosquash Rebase, Safe Push)

A common agent and CI workflow: fetch `origin` with pruning, fold all `fixup!` commits onto `origin/main`, generate a diff summary, and push safely with `--force-with-lease`.

```java title="PreparePullRequest.java"
Repository authored = repo.withAuthor("Dev Agent", "agent@example.org");
Remote origin = authored.remote("origin");

// 1. Update remote-tracking refs & prune stale branches
authored.fetch(origin, FetchOptions.defaults().prune());
RemoteBranch originMain = authored.remoteBranch("origin", "main");

// 2. Rebase current feature branch onto origin/main with --autosquash
RebaseResult rebased = authored.rebase(
    originMain,
    RebaseOptions.defaults().autosquash().allowConflicts()
);
if (rebased.isConflicted()) {
    throw new IllegalStateException("Rebase conflict in: " + rebased.conflicts());
}

// 3. Summarize changes for the PR description
Diff prDiff = authored.diff(originMain, authored.currentBranch(), DiffOptions.defaults().detectRenames());
System.out.println("PR scope: " + prDiff.formatShortStat());

// 4. Push safely (fails if someone else updated the remote branch)
authored.push(origin, PushOptions.defaults().forceWithLease().setUpstream());
```

### Recipe 2: Clean Up All Merged Feature Branches

```java title="CleanupMergedBranches.java"
Branch main = repo.branch("main");

for (Branch b : repo.mergedBranches(main)) {
    if (b.equals(main)) continue;
    System.out.println("Deleting merged branch: " + b.name());
    repo.deleteBranch(b);
}
```

### Recipe 3: Generate Release Notes Between Tags

```java title="ReleaseNotesGenerator.java"
Commit lastRelease = repo.getCommit("v1.0.0");
Branch main = repo.branch("main");

List<CommitDiff> changes = repo.logWithDiff(
    Log.range(lastRelease, main).noMerges(),
    DiffOptions.defaults().detectRenames()
);

System.out.println("## Changes since " + lastRelease.shortId());
for (CommitDiff item : changes) {
    System.out.printf("- %s (%s) —%s%n",
        item.commit().subject(),
        item.commit().shortId(),
        item.stat().formatShortStat());
}
```

}
