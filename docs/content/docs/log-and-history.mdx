## Simple Log Queries (`git log`)

Shorthand overloads cover the most frequent history lookups in a single line:

```java title="QuickLogs.java"
// Full history from HEAD
List<Commit> all = repo.log();

// Latest 10 commits (`git log -10`)
List<Commit> recent = repo.log(10);

// Starting from any CommitRef (Branch, RemoteBranch, Commit)
List<Commit> branchLog  = repo.log(repo.branch("main"), 20);
List<Commit> remoteLog  = repo.log(repo.remoteBranch("origin", "main"), 5);
List<Commit> fromCommit = repo.log(repo.getCommit("v1.0"), 10);

// Oneline formatting (`git log --oneline -10`)
for (Commit c : repo.log(10)) {
    System.out.println(c.shortId() + " " + c.subject());
}
```

## Fluent `Log` Queries

Combine commit ranges, topological ordering, merge filters, regex matching, date bounds, and path history simplification with the immutable `Log` builder:

```java title="FluentLog.java"
import dev.hoori.regit.*;
import java.nio.file.Path;
import java.time.Instant;

Branch main = repo.branch("main");
Branch feature = repo.branch("feature/auth");

List<Commit> commits = repo.log(
    Log.range(main, feature)              // main..feature
       .noMerges()                        // --no-merges
       .firstParent()                     // --first-parent
       .grep("^feat:")                    // --grep="^feat:"
       .author("Alix")                    // --author="Alix"
       .since(Instant.parse("2025-01-01T00:00:00Z"))
       .paths(Path.of("src/main"))        // -- src/main
       .order(Log.Order.TOPO)             // --topo-order
       .limit(25)                         // -n 25
);
```

### Ranges & Ref Selectors

```java title="LogRanges.java"
Branch main = repo.branch("main");
RemoteBranch originMain = repo.remoteBranch("origin", "main");

// Commits on main not yet on origin/main (origin/main..main)
List<Commit> unpushed = repo.log(Log.range(originMain, main));

// Symmetric difference (origin/main...main)
List<Commit> diverged = repo.log(Log.symmetricRange(originMain, main));

// Walk all refs, all branches, or all tags (`--all`, `--branches`, `--tags`)
List<Commit> acrossAll  = repo.log(Log.all().limit(50));
List<Commit> onlyMerges = repo.log(Log.branches().mergesOnly());

// Match an exact Identity (regex metacharacters are automatically escaped)
Identity alice = repo.headCommit().orElseThrow().author();
List<Commit> byAlice = repo.log(Log.of().author(alice));
```

## Log with Diff Statistics (`git log --stat`)

```java title="LogWithStat.java"
List<CommitDiff> entries = repo.logWithDiff(
    Log.of().limit(5),
    DiffOptions.defaults().detectRenames()
);

for (CommitDiff entry : entries) {
    System.out.println(entry.commit().shortId() + " " + entry.commit().subject());
    System.out.println(entry.diff().formatStat());
}
```

## Pickaxe Search (`git log -S`)

Finds commits where the number of occurrences of a search string changed in at least one file:

```java title="PickaxeSearch.java"
// Find when "LEGACY_FEATURE_FLAG" was introduced or removed
List<Commit> hits = repo.log(
    Log.of()
       .pickaxe("LEGACY_FEATURE_FLAG")
       .paths("src/main")
);

for (Commit c : hits) {
    System.out.printf("%s %s (%s)%n", c.shortId(), c.subject(), c.author().when());
}
```

## Line-Range History (`git log -L`)

Tracks the evolution of a 1-based inclusive line range backwards through history, adjusting line offsets across earlier edits:

```java title="LineHistory.java"
// Trace lines 10..25 of src/Parser.java starting from HEAD
List<LineLogEntry> evolution = repo.logLines(Path.of("src/Parser.java"), 10, 25);

for (LineLogEntry step : evolution) {
    System.out.printf("%s (lines %d..%d): %s%n",
        step.commit().shortId(),
        step.startLine(),
        step.endLine(),
        step.commit().subject());
    System.out.println(step.hunk().format());
}

// Or start from an explicit CommitRef
List<LineLogEntry> fromRelease = repo.logLines(repo.getCommit("v1.0"), "src/Parser.java", 1, 20);
```

## Merge-Base & Ancestry (`git merge-base`)

```java title="MergeBaseExample.java"
Branch main = repo.branch("main");
Branch topic = repo.branch("topic");
Commit release = repo.getCommit("v1.0");

// Check whether release is already an ancestor of main (`git merge-base --is-ancestor`)
boolean containsRelease = repo.isAncestor(release, main);

// Find the best common ancestor (`git merge-base main topic`)
Optional<Commit> commonAncestor = repo.mergeBase(main, topic);

// Find all maximal common ancestors in criss-cross merges (`git merge-base --all`)
List<Commit> allBases = repo.mergeBases(main, topic);
```
